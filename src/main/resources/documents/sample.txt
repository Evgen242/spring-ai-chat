Spring AI — это фреймворк для интеграции искусственного интеллекта в приложения на Spring Boot.
Он поддерживает различные LLM-провайдеры: OpenAI, Azure OpenAI, Ollama, Anthropic и другие.
Spring AI предоставляет абстракции ChatClient, EmbeddingClient, VectorStore и Advisor.

RAG (Retrieval-Augmented Generation) — это подход, при котором перед генерацией ответа
модель получает релевантные документы из векторного хранилища.

Векторное хранилище (Vector Store) — это база данных, которая хранит тексты в виде векторов
и позволяет искать по семантическому сходству.

Эмбеддинги (Embeddings) — это числовые представления текста, которые позволяют измерять
смысловую близость между разными текстами.

Function Calling — это возможность LLM вызывать внешние функции или инструменты,
чтобы получить актуальные данные или выполнить действия.

OpenRouter — это облачный сервис, который предоставляет доступ к разным LLM через единый API.
Маршрут openrouter/free автоматически выбирает доступную бесплатную модель.
OpenRouter совместим с OpenAI API и поддерживает стриминг, function calling и structured output.

Docker — это платформа для контейнеризации приложений, которая позволяет упаковать
приложение со всеми зависимостями в изолированный контейнер.

CI/CD — это практика автоматизации сборки, тестирования и развертывания приложений.
GitHub Actions — популярный инструмент для настройки CI/CD пайплайнов.
GitHub Actions позволяет автоматически запускать тесты, собирать Docker-образы и деплоить приложения.

Spring Boot — это фреймворк для быстрого создания Java-приложений.
Он предоставляет автоконфигурацию, встроенный сервер и готовые стартеры.

Spring AI — это часть экосистемы Spring для интеграции AI в Java-приложения.
Spring AI поддерживает ChatClient, PromptTemplate, Structured Output, RAG, Function Calling и Vector Store.
